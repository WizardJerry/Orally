# 编辑自包含的模型配置

2026-10-04，用户要求将主页与管线合并为一个配置编辑器，在顶部切换、保存、导入和
新建配置，下方分为语音识别与后处理两栏。后处理支持添加更多模型节点与 Prompt 子节点。

2026-10-05，用户进一步要求语音识别与后处理上下排列，统一 OpenAI 兼容服务的字段：
模型、服务地址、明文 API Key 和 Prompt；语音识别额外提供识别协议。

用户随后要求 ASR 自动识别协议，并在托盘菜单中快速切换已保存配置，用圆点标示当前
配置。

2026-10-06，用户要求全局测试直接录音，按全部未保存设置模拟一次 Voice Input，并提供
独立的 ASR 录音测试，不再依赖上传音频文件。

2026-10-08，用户要求统一使用 OpenAI 兼容服务，移除供应商专用默认值和路由。随后用户
报告通过 Chat Audio 提供的语音模型返回 HTTP 404 并要求修复。自动选择改为根据 HTTP
响应协商端点和音频编码，不再根据域名或模型名推断。

2026-10-09，用户要求精简设置页，配置统一放在程序同目录，快捷键通过直接按键录入，
替代预设列表。

2026-10-09，用户进一步要求移除 ASR Prompt 配置，将识别词汇留给后续词典功能，并
删除配置界面中的开发说明。这取代此前 ASR 与后处理表单统一提供 Prompt 的决定。

## 决策

当前 Desktop App 在现有 `config.toml` 中保存命名配置。每套配置包含自己的 ASR 参数和
有序的后处理模型。每个后处理模型拥有服务地址、凭据、模型名称、基础指令、模板、
失败回退选项和有序 Prompt 子节点。这些 Prompt 节点是当前配置的指令，不是共享的产品 Module。

ASR 编辑器提供服务地址、模型和 API Key；后处理还提供 Prompt 及有序 Prompt 子节点。
帮助文字只说明可用设置和操作，不展示开发说明。编辑器、共享运行时及 CLI 不再接受
可配置的 ASR Prompt。语音命令不再接受 `--prompt`，也不读取 `ORALLY_ASR_PROMPT`；
文本后处理保留 Prompt 选项。旧 ASR Prompt 载入时忽略，再次保存时移除。词典功能仍为
后续计划。API Key 默认遮挡，可通过眼睛
按钮切换显示，仍以明文保存。现有语言、环境变量、用户
模板及回退值继续保留在配置中，精简的服务表单不再编辑这些参数。
桌面识别和测试使用 `auto`，界面隐藏协议选项。配置加载、序列化及编辑器将旧值规范为
`auto`，保留地址、模型、凭据及语言提示。自动选择先尝试 multipart
`/audio/transcriptions`，仅 HTTP 404/405 才切换到 `/chat/completions` 的 Chat Audio。
该请求的用户内容只有一个 `input_audio`，包含 WAV Data URL，不添加 `format` 或文本
片段；已有语言提示作为可选系统上下文。仅 HTTP 400/422 才继续尝试原始
Base64 加 `format: "wav"` 及固定文本转写指令。鉴权失败、限流、服务器错误、网络异常、
空文本和成功响应解析失败均终止识别。成功格式在同一个提供方实例的后续分块中复用。
CLI 可显式指定 multipart 或标准原始 Base64 Chat Audio。没有域名或模型专用分支及
供应商 SDK。
原生 multipart 请求先在内存中准备包含 WAV 的完整表单，避免阻塞上传桥接层将提前
返回的 HTTP 拒绝误报为请求体错误。非成功响应即使正文读取失败，也保留已收到的
HTTP 状态；只有上述状态码允许继续协商协议。

设置页移除输出语言、配置文件位置和 Portable 控件，`config.toml` 始终位于可执行文件
旁。若目标不存在，从原环境变量、AppData 或 home 位置复制有效旧配置，不删除源文件，
不覆盖已有目标；读取和解析失败会明确报错。这取代此前可选的配置便携路径优先级，
完整 Portable Installation 的其他数据契约仍属后续设计。

唯一可配置的快捷键是全局开始/停止听写。点击控件后直接按键，组合仍保存在
`hotkey.preset` 中。保存时立即注册，注册或写盘失败保留旧绑定。录入期间临时释放旧
绑定，完成、按 Esc 或失焦时恢复。设置窗口保留固定 Ctrl+S 保存，不再存储演示用的
编辑及窗口快捷键。

AI 模式下，启用的模型按页面顺序运行。第一个模型接收 Raw Transcript（原始转写文本），
后续模型接收上一步输出。启用且非空的 Prompt 子节点按可见顺序追加到所属模型的系统
指令中。全部模型禁用时直接保留 Raw Transcript。原始输出选项绕过所有后处理，本地
模式沿用已有基础清理。

服务连通性测试按当前草稿的模型和凭据发送真实请求，ASR 自动协商协议，不使用本地
回退。输入输出测试弹窗默认采集麦克风音频，再运行识别和完整后处理链，同时提供仅 ASR 录音模式及
文本后处理模式。开始录音时捕获当前配置和全局设置的草稿，无需上传文件。桌面端复用
CPAL，浏览器在内存中生成 PCM16 WAV。取消、关闭弹窗、切换配置或页面生命周期变更
会释放录音资源。每次录音最多两分钟、15 MiB。测试不保存、插入或写入历史，遵守禁止
外部请求设置，并用警告说明使用了已配置的本地回退。浏览器测试直接采用相同请求格式，
需要 CORS；原生测试复用已有适配器。语音与 LLM 可以共用地址和凭据，但各自的模型
必须支持对应接口；LLM 连通性测试成功不能验证 ASR 模型或端点。

在这些配置的编辑器范围内，本决策取代
[ADR-0002](0002-compose-modules-into-one-request.zh-CN.md) 的单次请求限制。
[ADR-0003](0003-share-provider-connections-across-workflows.zh-CN.md) 的共享 Service
Connection，以及 [ADR-0006](0006-store-workflows-in-sqlite-and-modules-as-toml.zh-CN.md)
的 SQLite 产品 Workflow 仍为 Deferred；当前编辑器不实现这些存储或共享契约。

## 后果

切换配置保留草稿。保存时写入配置列表，并将选中配置复制到现有顶层 `asr` 与
`postprocess` 字段。输出、录音、热键和隐私仍为全局设置。没有配置列表或模型数组的旧
TOML 保持原有行为。CLI 命令保持已有的单模型行为。
托盘使用稳定 ID 列出已保存配置，以圆点标示当前配置。切换立即保存选中的 ID 并同步
服务设置；保存配置或新名称会刷新菜单。设置窗口接收切换事件，读取最新保存配置，同时保留
已修改的配置草稿和全局设置草稿。共享配置读写锁串行处理托盘切换和编辑器保存。

JSON 导出包含一套配置及其中直接填写的凭据。导入 JSON 或现有 TOML 会创建新的草稿，
不覆盖当前配置。原生应用负责解析 TOML；浏览器预览单独保存本地草稿。

每个模型沿用已有失败契约：开启本地回退时，请求失败后进行本地清理，后续模型可以
继续处理清理结果。缺少凭据或适配器构建失败仍会终止处理。历史中 Raw Transcript 与
Final Text（最终文本）保持分离。
