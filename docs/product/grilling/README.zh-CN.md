此文件夹不是共享语音重构或后续以后端优先的重构所使用的 Active 需求来源。具体工作应记录在经过评审的[架构基线](../../engineering/refactor-baseline.zh-CN.md)和 GitHub Issues 中。

这些说明应聚焦产品方向，而不是实现细节。

单次探索性的 Grilling 产物可以只保留英文；当其中的结论被提升到产品文档、架构基线或 ADR 时，应按照仓库语言政策提供英文/简体中文配对。
