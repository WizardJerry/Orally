# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for issue operations inside this clone.

Repository: `WizardJerry/Orally`

PRs as a request surface: no.

When a skill says "publish to the issue tracker", create a GitHub issue.

When a skill says "fetch the relevant ticket", run `gh issue view <number> --comments`.

Use labels from `.agents/triage-labels.md` when triaging issues.
